# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- Agentic loop pattern for iterative workflow execution
- Human-in-the-loop feedback mechanisms
- Plan refinement based on evidence
- Feedback, refine, and stop API endpoints
- Comprehensive agentic loop documentation

## [0.1.0] - 2024-01-XX

### Added
- Initial release
- Temporal workflow orchestration
- Policy enforcement with approval gates
- PostgreSQL and memory storage backends
- External service integration (A2A agents, MCP servers)
- Plugin system for custom agents and tools
- Prometheus metrics and structured logging
- Distributed tracing support
- Health checks and graceful shutdown
- Rate limiting middleware
- Input validation and sanitization
- Docker and Kubernetes deployment support
- Comprehensive documentation

### Features
- **Workflow Orchestration**: Temporal-based reliable workflows
- **Storage**: PostgreSQL with automatic migrations
- **External Services**: Connect to cloud-hosted agents (AWS, GCP, Azure, Hugging Face)
- **Plugins**: Extensible agent and tool system
- **Observability**: Metrics, logging, tracing
- **Security**: Input validation, rate limiting, authentication
- **Deployment**: Docker, Docker Compose, Kubernetes
